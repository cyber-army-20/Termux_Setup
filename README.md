# 🚀 Termux  Environment Setup

এই রিপোজিটরিতে টারমাক্স (Termux) অ্যান্ড্রয়েড অ্যাপ্লিকেশনের জন্য প্রয়োজনীয় পরিবেশ সেটআপ করার কমান্ডগুলো দেওয়া হয়েছে। এটি ব্যবহার করে আপনি আপনার মোবাইলেই বেসিক হ্যাকিং ও প্রোগ্রামিং শুরু করতে পারবেন।

## 📌 যা যা সেটআপ হবে
* **সিস্টেম আপডেট:** সর্বাধুনিক প্যাকেজসমূহ।
* **স্টোরেজ অ্যাক্সেস:** ফোনের ইন্টারনাল স্টোরেজ ব্যবহারের সুবিধা।
* **পেকেজ:** php,openssh,curl,figlet,nmap,java,ruby,zip,unzip,wget,tor,python2,espeak,rust,tur-repo।
* **মডিউল:** bs4,faker,mechanize,httpx,requests,rich,Flask,fake_email,pyzipper,hashlib,bcrypt,httplib2,pycurl,user_agent,smtplib।



## 🛠️ সেটআপ করার নিয়ম (ধাপে ধাপে)

টারমাক্স ওপেন করুন এবং নিচের কমান্ডগুলো একেবার পেস্ট করুন:


```bash
pkg update -y
pkg upgrade -y
pkg install python -y
pkg install git -y
git clone https://github.com/cyber-army-20/Termux_Setup
python termux_setup.py
```
